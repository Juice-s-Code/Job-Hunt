# Give this to your Codex

Clone or download [the public toolkit](https://github.com/Juice-s-Code/Job-Hunt),
open its folder in your own Codex, and paste this. Python 3.10+ runs the local tools.

```text
Read AGENTS.md, CODEX.md, README.md and docs/PLAYBOOK.md. Run the synthetic tests
and explain any failures. Help me start or continue my own job hunt. Ask for MY
resume/evidence, experience, preferred jobs, countries, locations, availability
and pay rules in small batches. Do not inherit anyone else's candidate facts.

If starting fresh, ask me to approve a private vault outside this repository,
initialize it and complete my profile with my approved answers. If continuing,
follow docs/MIGRATION.md and reconcile existing applications before new ones.

Build a sourcing/research plan. Explain which steps your current tools support
and which need me. Agree with me on application permissions and an alert channel.
Do not apply, send messages, connect accounts or activate scheduling during setup.
Leave a private handoff so the next session can continue without repeating work.
```

Later, paste [prompts/CONTINUE.md](prompts/CONTINUE.md). For scheduled research and
alerts, use [prompts/SET-UP-ALERTS.md](prompts/SET-UP-ALERTS.md) after one manually
checked cycle. No original author's private files or accounts are needed.
